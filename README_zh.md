# TG-ResGCN Test100 数据集

[English](README.md) · [数据格式](DATA_FORMAT.md)

本数据集包含用于模块化微反应堆负荷跟踪评测的100条冻结目标功率曲线。相关论文尚未发表，目前仅公开Test100测试数据集；论文发表后将公开完整研究数据集和训练代码。

本包不包含训练与验证曲线、模型权重、训练实现、训练日志或内部研究记录。

## 文件

- `profiles/`：100个NumPy `.npy` 数组，逐字节保留冻结Test100输入。
- `manifest.json`：曲线编号、相对文件路径、完整时域 `H`、SHA-256及曲线类别。
- `DATA_FORMAT.md`：采样间隔、单位、时域定义和类别数量。
- `MANIFEST.sha256`：除哈希清单本身外的全部文件校验值。
- `LICENSE`：沿用已有数据仓库的许可证原文。

每条曲线包含 `H+1` 个采样点，间隔为1秒，数值为额定功率的比例。评测应覆盖全部 `H` 个控制区间；最后一个采样点是时刻 `H` 的边界值。各曲线时域为200至433秒，100条曲线合计24,894个控制区间。

本包仅包含数据和说明，不含实现代码、模型检查点或评测成绩。为保持数据身份，保留原曲线编号及类别标签；编号不表示本包中的训练或验证用途。未生成或替换任何输入曲线。
